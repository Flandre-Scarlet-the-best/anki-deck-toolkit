# Ревью обновлений зависимостей

Рассматривай PR Renovate, Dependabot и других обновлений зависимостей как
полноценные изменения: успешный CI и тип версии сами по себе не доказывают
совместимость. Сверяй реальные ограничения, API, вызывающий код, платформы,
транзитивные зависимости, уязвимости и лицензии в затронутой области. Изменение
minor в версии `0.x` не гарантирует обратную совместимость.

Для Rust проверяй согласованность `Cargo.toml`, `Cargo.lock`, resolver,
`rust-toolchain.toml`, workspace MSRV и зависимых констант, идентичности
backend, ресурсов и тестов. Для GitHub Actions проверяй совместимость с
используемым окружением и существующей политикой CI. Для Python сверяй
`requirements.in` с генерируемым `requirements.txt`, хеши и метаданные всех
ограничений, особенно при установке без разрешения зависимостей. Учитывай
текущую политику Renovate для Resemble; не предполагай, что независимое
обновление CUDA-пакета совместимо с фиксированным PyTorch без доказательства.

Отделяй установленный конфликт от риска, который ещё нужно проверить. Предлагай
патч или план, но не коммить автоматически в ботскую ветку. Перед отдельным
явным исправлением по запросу владельца предупреди, что изменения ветки могут
остановить её автоматическое сопровождение Renovate, и дождись осознанного
выбора владельца.
