## 下载的第三方素材

本项目**不主张**对来自 Yarxi、JPDB 或其他外部来源的图片、音频、字体、
语料库等素材拥有作者身份、版权或授予许可的权利。

下载、验证、转换、缓存或将这些素材存入 `.asset-store/`、
`decks/**/media/`，均**不会**使版权转移给本项目，也不会自动使其采用 AGPL-3.0。
原权利人的版权、许可及来源条款仍然适用。技术上可以获取文件，
不等于获得再次分发的许可。

项目包含的参考素材仍遵循各自的许可和署名要求。例如，来源于 KanjiVG
的参考数据涉及 CC BY-SA 3.0，而来源于 Noto Serif JP 字体的参考数据
涉及 SIL Open Font License 1.1。来源和署名信息保存在相关数据旁，
例如 `tools/asset-store/src/data/*-ATTRIBUTION.txt`。
项目的源代码许可证不能取代这些独立条款。

## 用户数据与程序输出

仅仅使用本工具，不会将用户的 CrowdAnki 导出、笔记、牌组、
媒体文件或 `decks/` 数据许可给工具作者。

本项目**不会自动向程序生成或转换的文件附加自己的许可证**：
包括 JSON 导出、HTML 报告、图片、中间文件及其他输出。
运行本程序本身不会使这些输出自动受到 AGPL-3.0 约束。

但这**不意味着**输出没有版权、属于公有领域或允许无限制使用。
相关权利可能属于用户、输入内容的原权利人或其他主体。
若输出实质性包含程序自身受版权保护的内容，则相应许可仍可能适用。
第三方输入及其衍生素材继续受适用条款约束。

`decks/` 与 `.asset-store/` 目录整体被 Git 忽略。
仅仅将内容保存在这些目录中，不会使其成为公开发布的源代码，
也不会因此受到本项目 AGPL 代码许可证的约束。

除原权利人实际授予的许可外，本项目不授予对第三方素材的其他使用权。
公开再分发下载或衍生素材前，应自行核对适用条款与权利。
判断文件的法律状态，应以原始权利声明为准，而非目录名称或是否由程序生成。
