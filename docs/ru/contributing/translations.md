# Переводы пользовательской документации

## Источник истины

Русский язык (`docs/ru/`) — основной и поддерживаемый язык технической документации. Английский и упрощённый китайский переводы (`docs/en/`, `docs/zh-CN/`) сохранены для читателей, но могут устаревать. При расхождении контрактов приоритет имеет русский текст.

## Участие сообщества

Приветствуются PR с переводами, вычиткой, исправлениями и дополнениями. Переводы могут обновляться независимо друг от друга; создание или правка русской страницы не требует одновременно обновлять все локализации. Сопровождающий может периодически синхронизировать переводы (ориентир — раз в неделю), но не гарантирует регулярность или актуальность.

Не изменяйте технический смысл CLI-команд, флагов, схем, UUID, путей и форматов данных ради локализации. Для страниц, у которых нет перевода, допустима ссылка на русский оригинал.

## Организация

Документация размещается по схеме `docs/<язык>/<модуль>/<файл>.md`; общие разделы имеют отдельные каталоги `performance/`, `licensing/`, `contributing/`. Корневой `README.md` — краткая точка входа GitHub. `LICENSE` и агентские инструкции остаются на штатных местах.

Маркеры `i18n-source-git-blob`, требование одновременного наличия языковой тройки и CI-гейт актуальности переводов больше не используются. Сохраняются общие проверки работоспособности ссылок и технические контракты снимков производительности.
